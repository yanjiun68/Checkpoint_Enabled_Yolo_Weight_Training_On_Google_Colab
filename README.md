# Checkpoint_Enabled_Yolo_Weight_Training_On_Google_Colab
This is the modified computer vision weight training google colab notebook that is created for Yolo weight training that allows user to continue from halted training files. 

Main feature : 
When the dataset training has been interrupted mid way  , recovery section code blocks will continue from the interrupted epoch progress , which avoid restarting on every failure such as GPU inferencing failure , timeout etc... 
All the trained Yolo inference weight files will be stored into Google Drive.
